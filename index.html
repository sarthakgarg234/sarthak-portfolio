About Me

About Me

Developer. Problem Solver. Continuous Learner.

Sarthak Garg is a backend-focused web developer based in Dehradun, Uttarakhand, India, with hands-on experience in developing, customizing, maintaining and optimizing websites and web applications. He primarily works with PHP, Laravel, WordPress and MySQL, focusing on building reliable backend systems, dynamic websites, efficient database structures and scalable web solutions that meet business requirements.

His professional experience spans a diverse range of projects, including corporate business websites, government-related platforms, WooCommerce e-commerce stores, custom PHP applications, content management systems and backend API integrations. He has worked with WordPress themes, custom page layouts, Advanced Custom Fields (ACF), Gutenberg blocks and reusable components to create flexible websites that are easy to manage and maintain. His experience also includes implementing dynamic content, managing website navigation, improving responsive layouts, troubleshooting functional issues and integrating third-party services to enhance website functionality.

Alongside his WordPress development work, Sarthak has experience working with Laravel's MVC architecture, routing, controllers, models, database migrations, validation and REST API development. He understands the importance of structured code, efficient database management and dependable application workflows. His work with MySQL and backend logic enables him to develop data-driven applications that support business operations and provide a consistent user experience.

In addition to backend development, Sarthak is comfortable working with HTML, CSS, JavaScript, Bootstrap and Ajax for frontend integration and responsive user interfaces. He uses Git and GitHub for version control and collaborative development, and he is familiar with Linux-based server environments, Nginx configuration, application deployment, production troubleshooting and WordPress security hardening. He also has practical exposure to cloud deployment workflows involving AWS services such as EC2 and database hosting environments.

Sarthak believes that successful web development goes beyond writing code. It requires understanding business needs, maintaining clean and maintainable implementations, identifying issues efficiently and ensuring that applications remain secure, responsive and performant. He approaches each project with a focus on functionality, usability, reliability and continuous improvement, while remaining open to learning new technologies and exploring better ways to solve technical challenges.

His goal is to continue growing as a backend and web developer by working on challenging projects, strengthening his expertise in modern web technologies and expanding his knowledge of cloud infrastructure, deployment automation and DevOps practices. He aims to build practical, scalable and secure digital solutions that deliver long-term value to businesses and their users.
